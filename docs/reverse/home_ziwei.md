## 二、首页紫微页签（模块 2430）

首页 Tab 为 `["在线起卦", "八字轻测", "紫微斗数"]`，第三个页签渲染模块 2430：

```
命主性别: (男) (女)                   ← 本工程默认选中"男"
日期类型: (阴历) (阳历)                ← 本工程默认选中"阴历"
出生日期: [2026-09-18 10:30]          ← 与八字轻测共用同一份，官方 DatePick
出生城市: [省  市 ▾]  ☑使用真太阳时  ⓘ
┌──────────────────────────────┐
│ 问题描述                      │      ← 多行输入，≤100 字
└──────────────────────────────┘
1、请描述具体求测问题，便于老师针对性解答。
2、输入多个问题时，老师仅分析第一个问题。
3、时辰不清楚，可备注大概时间(如3-5点)。
              [ 紫薇排盘 ]
```

> 版式差异：官方模块 2430 把"求测问题"（`maxLength: 50`，无提示文案）排在最前；
> 本工程按需求将该字段移到「出生城市」之后，并与首页「八字轻测」面板
> （模块 2423）统一为"多行输入框 + 三条填写提示"的版式。
> 校验仍沿用官方 `_ziWeiPaiPan()`，仅取输入文本，不受控件版式影响。

### 本工程按需求调整的四处（与官方实现的差异）

| 项 | 官方实现 | 本工程 |
| --- | --- | --- |
| 命主性别初值 | `state.sex = -1`（未选中） | 默认选中「男」(`1`) |
| 日期类型初值 | `state.dateType = -1`（未选中） | 默认选中「阴历」(`0`) |
| 出生日期 | 各页签各自持有 `state.time`（默认当前时间） | 由首页卡片统一持有，**八字轻测与紫微斗数共用同一份**，任一页签修改后另一页签同步 |
| 出生城市 | `UnionPicker`（模块 2424）单框展示 + 弹层 `CommonPicker`（模块 1864）级联双滚轮 | 同款：页面仍是**单框展示**（文本 + 下拉箭头），弹框内**省 / 市两列滚轮并列联动**（切换省份后城市列表刷新），弹层含 `取消 / 确定` 与 `省 / 市` 标题行 |

因为性别与日期类型已有默认值，官方第 2、3 条校验（`请选择性别` / `请选择阴/阳历`）
在本工程中作为兜底保留，正常操作不会再触发。

### 校验逻辑 `_ziWeiPaiPan()`

| 顺序 | 条件 | 官方文案 |
| --- | --- | --- |
| 1 | 求测问题为空或长度 < 2 | `请输入求测问题~` |
| 2 | `state.sex == -1` | `请选择性别` |
| 3 | `state.dateType == -1` | `请选择阴/阳历` |
| 4 | 勾选真太阳时且未选出生地（`_checkArea()`） | `请先选择出生地点` |
| 5 | 未登录 | 跳转登录页 |

### 提交参数 `yjhapp/ziWeiQiGua`

```js
{
  desc, gender: sex === 0 ? 2 : 1,        // 女 2 / 男 1
  'calendar-year': dateType === 0 ? 2 : 0, // 阴历 2 / 阳历 0
  year, month, day, hour, min,
  province: secendData.value, city: firstData.value,
  isUseSunTime, leapmonth: 0, chatRoomId: -1,
}
```

出盘成功后调用 `_saveOrderData()` 提交 `yjhapp/saveOrder`
（`type: 34`、`fromurl: 配置appTarget_homezw`），再跳转 `ZiWeiResult` 并 toast
`排盘成功，请稍后`；失败提示 `排盘失败，请重试~`。

## 三、命盘渲染（模块 2569 / 2570 / 2581）

命盘为经典 4×4 宫格，`getGongView(t)` 的 `t` 为**地支序号（子 = 0）**，
`gongIndex(t) = firstGongIndex - t` 定位到 `gong12` 数组：

```
┌──────┬──────┬──────┬──────┐
│ 巳 3 │ 午 4 │ 未 5 │ 申 6 │   ← 上排
├──────┼──────┴──────┼──────┤
│ 辰 2 │             │ 酉 7 │
├──────┤   中 宫 2×2  ├──────┤
│ 卯 1 │             │ 戌 8 │
├──────┼──────┬──────┼──────┤
│ 寅 0 │ 丑 11│ 子 10│ 亥 9 │   ← 下排（命宫就位于本命地支）
└──────┴──────┴──────┴──────┘
```

宫格内容（模块 2570）自上而下：星曜（`xing`，含 `name` / `level` / `wangDu` /
`gongSihua`）、身宫标记（`isShenGong`）、四组十二神
（`boShi` / `taiSui` / `jiangQian`），底部一行 `daXian` / `gongName` /
`wuXing` / `ganZhi`。

中宫（模块 2581）展示：

| 位置 | 字段 | 文案（i18n `bus.zwGuaXiang`） |
| --- | --- | --- |
| 第 1 行 | `yinYang` + `wuXingJu` | `{阴阳}  命局:{五行局}` |
| 第 2 行 | `theTime` | `阳历:{公历}` |
| 第 3 行 | `nongLi` + `sizhuZhi[3]` | `农历:{农历}  {时支}时` |
| 第 4 行 | `mingZu` / `shenZu` | `命主:{命主}  身主:{身主}` |
| 第 5~6 行 | `sizhuGan` / `sizhuZhi` | 四柱天干行 / 地支行 |
| 底部 | `prompt1/2/3` | `身宫` / `先天` / `大限` 图例 |

## 四、本地排盘引擎（`lib/models/ziwei.dart`）

官方客户端**没有**排盘算法（全部由服务端 `ziWeiQiGua` 下发），因此本地按传统
安星诀实现，并用开源实现 iztro 作为校验基准，逐宫比对：

| 步骤 | 规则 | 说明 |
| --- | --- | --- |
| 农历换算 | `lunar_calendar.dart` | 直接复用官方模块 1898 的移植（1900–2100） |
| 年干支 | 农历年（正月初一为界） | 除夕晚子时不进位 |
| 命宫 | 寅起正月顺数至生月，再逆数生时 | `soulIndex = 月序 − 时支序`（寅 = 0） |
| 身宫 | 寅起正月顺数至生月，再顺数生时 | `bodyIndex = 月序 + 时支序` |
| 宫干 | 五虎遁（甲己之年丙作首） | 复用 `ganzhi.dart::monthGanZhi` |
| 五行局 | 命宫干支纳音取数 | 水二 / 木三 / 金四 / 土五 / 火六 |
| 紫微 | 局数除日数，商数宫前走 | `ziweiIndexOf(day, 局数)` |
| 天府 | `−紫微`（寅申同宫、对称） | |
| 十四主星 | 紫微系逆布、天府系顺布 | 天机−1、太阳−3、武曲−4、天同−5、廉贞−8；太阴+1…七杀+6、破军+10 |
| 六吉六煞 | 左辅右弼（月）、文昌文曲（时）、天魁天钺（年干）、禄存擎羊陀罗（年干）、火星铃星（年支+时）、地空地劫（时）、天马（年支三合） | |
| 生年四化 | 十天干四化表（禄权科忌） | 庚：太阳 / 武曲 / 太阴 / 天同 |
| 命主 / 身主 | 命宫地支 / 年支查表 | |
| 十二宫名 | 自命宫逆行（命宫、父母、福德…） | |
| 十二神 | 长生（五行局起）、博士（禄存起）、将前（年支三合）、岁前（年支起岁建） | 阳男阴女顺行、阴男阳女逆行 |
| 大限 | 命宫起，局数为起运岁，每宫十年 | |
| 晚子时 | 23:00 后按次日安星与日柱 | 时支仍为子 |

### 校验（`test/ziwei_test.dart`）

* 24 组固定样例（`test/fixtures/ziwei_reference.json`，由
  `tools/reverse/generate_ziwei_reference.mjs` 调用 iztro 生成）：
  农历、四柱、五行局、命主身主、命宫/身宫地支、十二宫的宫名 / 宫干 /
  主星（含庙旺与四化）/ 辅星 / 四组十二神 / 大限区间**全部逐项比对一致**；
* 额外边界：除夕晚子时、闰月十五/十六、闰六月廿八等四柱场景；
* 起紫微星诀按水二局、火六局的公开星表校验；
* 开发期另以 200 组随机日期（1902–2098 年、随机时辰与性别）跑通全量比对。

## 五、实现映射

| 官方行为 | 本地实现 |
| --- | --- |
| 首页紫微页签表单（模块 2430） | `lib/widgets/ziwei_form.dart` |
| 命盘渲染（模块 2569/2570/2581） | `lib/pages/ziwei_chart_page.dart` |
| 排盘引擎 | `lib/models/ziwei.dart` |
| 出生地经度与真太阳时 | `lib/models/city_longitude.dart` |
| 出生地省市数据 | `lib/models/china_area.dart`（`kUnionAreaData`，官方模块 2427） |
| 农历 / 干支 | `lib/models/lunar_calendar.dart`、`lib/models/ganzhi.dart`（官方模块 1898 / 2111） |

### 本地适配说明

1. 官方由服务端出盘（`yjhapp/ziWeiQiGua`）与保存求测单（`yjhapp/saveOrder`），
   本地改为直接按传统安星诀计算并跳转命盘页；
2. 命盘页只渲染**先天命盘**（十二宫 + 星曜 + 四化 + 大限 + 四组十二神），
   官方的解卦文案、流年/流月盘、命盘截图与保存记录依赖服务端数据，未实现；
3. 真太阳时：官方由服务端处理（客户端只上报 `isUseSunTime`），本地按
   `(经度 − 120) × 4 分钟` 做经度修正（未含均时差），经度表覆盖省会与主要城市，
   其余城市回退到省会，未收录地区不修正；
4. 四柱口径：紫微斗数以农历年为基准（四化、命主、身主、大限均据此），
   与官方八字模块（节气口径，模块 2111）不同，两者互不影响。
